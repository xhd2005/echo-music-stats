# 听歌统计

> EchoMusic 插件：本地化的听歌统计报告。自动记录每一次播放，生成总时长 / Top 歌手 / Top 歌曲 / 时段分布 / 音源占比 / 年度报告，数据 100% 保存在本机。

## 功能特性

- **静默采集**：启用后自动记录每次播放，无需任何操作；暂停不重置、seek 取最大进度、切歌立即结算上一首
- **去重可靠**：同一首歌的连续播放只记 1 条（`track_id + started_at` 唯一索引兜底），无重复行
- **最短计入时长可配**：默认实听 ≥ 30 秒才计入，可在设置中改为 10 / 30 / 60 / 120 秒
- **时间范围筛选**：全部 / 近 7 天 / 近 30 天 / 本月 / 今年，切换即时重查
- **四宫格 KPI**：总听歌时长、总播放次数、去重歌曲数、去重歌手数
- **五类可视化**：听歌时长趋势（折线）、Top 歌手（条形）、Top 歌曲（列表）、每日时段分布（柱状）、音源占比（donut），全部为自绘内联 SVG，无外链、无 npm 依赖
- **年度报告**：选择「今年」时页面顶部出现高亮卡，展示今年总时长 / 总次数 / 最爱歌手 / 最爱歌曲 / 最活跃月份 / 平均每天
- **一键清空**：设置面板内二次确认后删除全部记录
- **隐私优先**：数据仅存本机插件目录，无任何网络上报

## 安装

1. 打开 EchoMusic → 设置 → 插件管理
2. 方式一（推荐）：插件市场添加源 `https://github.com/xhd2005/echo-music-plugins` 后搜索「听歌统计」安装
3. 方式二：把本文件夹（或它的 zip 压缩包）拖入插件管理页面的本地安装区
4. 在插件列表中找到本插件并打开启用开关

## 使用说明

- **查看报告**：左侧侧边栏「插件」分组 →「听歌统计」，或运行命令 `music-stats:open`（可在快捷键设置中绑定）
- **切换范围**：页面顶部点击 全部 / 近 7 天 / 近 30 天 / 本月 / 今年
- **年度报告**：把时间范围切到「今年」即显示
- **插件设置**：设置 → 插件管理 → 听歌统计 → 打开插件设置，可关闭采集、调整最短计入时长、清空数据
- **页面路由**：`/main/plugin/music-stats/report`

## 计入规则

- 实听时长 `>= 最短计入时长`（默认 30 秒）→ 写入 1 条记录；低于阈值丢弃
- 暂停不重置、拖动进度不影响（取最大播放进度）
- 切换歌曲 / 停止播放 / 禁用插件 → 立即结算上一首
- `title` 或 `artist` 解析为空 → 跳过（如无歌手信息的本地文件）

## 常见问题

- **报告为空**：确认已开启「启用统计」，且播放时长达到最短计入时长；统计只覆盖启用之后发生的播放
- **时长和实际不符**：统计的是「实听时长」（播放进度推进量），暂停期间不计入；与歌曲本身的完整时长无关
- **音源占比里的「在线曲库」**：宿主对在线歌曲的 `source` 字段为空、云盘/本地歌曲为 `cloud`，插件据此归类展示；在线曲库不区分具体平台（网易/QQ/酷狗等）
- **清空后无法恢复**：清空为不可逆操作，请谨慎确认

## 技术说明

- 能力声明：`capabilities.sqlite` —— 通过宿主 `ctx.sqlite` 打开本地库，落库与查询均在主进程插件沙箱内完成
- 采集事件：`ctx.events.onTrackChange`（切歌/元数据解析，带同 id 去抖）+ `ctx.events.onTimeUpdate`（取最大播放进度）
- 表结构：单表 `plays`，含 `idx_plays_once`（去重）、`idx_plays_month`、`idx_plays_day` 索引；查询均为 `WHERE started_at >= ? AND started_at < ?` 范围扫描
- 图表为自绘 SVG（折线 / 条形 / 柱状 / donut），遵循单序列主色、图例标注、文本用文字色而非系列色的可视化规范
- 遵循 EchoMusic 插件规范：ESM 入口导出 `activate/deactivate`，渲染函数 + 宿主组件，样式以 `.mst-` 前缀隔离，明暗主题随宿主 CSS 变量自适应
